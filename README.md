# JuYi 🏯

线上地址：**[ju3928.github.io/JuYi](https://ju3928.github.io/JuYi/)**

## 运行方式

- **独立运行**：双击任意 `modules/xxx/index.html` 即可，不依赖服务器
- **首页导航**：打开根目录 `index.html`，通过卡片导航进入各模块
- **线上访问**：`https://ju3928.github.io/JuYi/`

> ⚠️ 数据存储在浏览器 IndexedDB 中，完全本地。更换设备/域名需通过各模块的导出/导入功能迁移数据。

## 模块一览

### 📒 错题本

图文混排错题管理，支持复习模式。

| 功能 | 说明 |
|------|------|
| 图文混排 | 题目和解析支持文字+图片，Ctrl+V 粘贴截图 |
| 普通/难题分类 | 二分类标记，支持单独筛选难题 |
| 科目分类 | 预设政治/英语/数学/数据结构/计组/操作系统/计网，支持自定义 |
| 标签系统 | 自由打标签（真题、易错、公式等），跨模块统一 |
| 复习模式 | 单题卡片，按添加时间排序，断点续复习 |
| 搜索 & 筛选 | 科目、标签筛选 + 全文搜索 |
| 导出导入 | JSON 格式备份（含图片 base64），跨设备恢复 |

> 详见 [modules/error-notebook/README.md](modules/error-notebook/README.md)

### 📝 做题本

结构化刷题工具，支持选择题/填空题/解答题，含答案核对。

| 功能 | 说明 |
|------|------|
| 多题型支持 | 选择题（单选/多选）、填空题、解答题 |
| 子题拆分 | 每题可拆分为多空/标签（如 3.1、3.2），独立作答 |
| 答案汇总 | 右侧面板实时汇总所有答案，一键复制 |
| 正确答案核对 | 录入正确答案后逐题比对，显示对错统计 |
| 做题本管理 | 创建/编辑/删除做题本，题目数量可配置 |
| 代码编辑器 | 解答题支持代码编辑器，自动行号、自适应高度 |

### ⚔️ 战报板

算法竞赛备战面板，Rating 追踪 + 题库管理 + 算法模板。

| 功能 | 说明 |
|------|------|
| Rating 趋势图 | Canvas 绘制多平台 Rating 曲线（LeetCode / NowCoder / Codeforces） |
| 战绩截图 | 每场比赛可附带截图，灯箱查看 |
| 题库管理 | 题号/题名/链接/算法标签，支持搜索与排序 |
| 算法模板库 | 代码模板沉淀，含核心思路、复杂度、代码编辑器 |
| 模板关联 | 题目与模板多对多关联 |
| 标签筛选 | 算法标签筛选题目和模板 |

### 🏃 健身

体重追踪与运动日志。

| 功能 | 说明 |
|------|------|
| 体重曲线 | Canvas 绘制体重变化趋势图，支持缩放 |
| 运动日志 | 记录运动类型、时长、强度 |
| 强度统计 | 按运动类型统计总时长/次数 |
| 标签筛选 | 按标签过滤运动记录 |

### 🐚 拾贝

个人知识卡片管理与每日 AI 美言推荐。

| 功能 | 说明 |
|------|------|
| 知识卡片管理 | 添加/编辑/删除卡片，支持图文混排，Ctrl+V 粘贴截图 |
| 分类系统 | 预设数学公式 / 408专业课 / 英语美言，支持自定义分类 |
| 标签系统 | 自由标签，逗号分隔，按标签筛选 |
| 每日 AI 美言 | 每日自动生成一句考研英语美言（含英文原句、中文翻译、主题标签） |
| 智能去重 | 自动检测与已收藏卡片的重复，确保句子独一无二 |
| 一键收藏 | 将当前美言保存为知识卡片，自动归类与附标签 |
| 搜索排序 | 按标题/正文关键词搜索，按时间排序 |
| 导出导入 | JSON 格式备份（含图片 base64），跨设备恢复 |
| 暗色模式 | 跟随系统主题，护眼阅读 |

### 📅 计划表

考研日程规划 + 每日打卡 + 可视化日历。

| 功能 | 说明 |
|------|------|

| 月历视图 | 右侧面板月历，每日红→绿渐变背景 + 百分比数字 |

| 月度勤奋指数 | 本月完成率≥80% 的天数占比 |
| 一键勾选 | 一键勾选当日所有固定任务 |
| 动态鸡汤 | 根据当前勾选状态显示不同激励文案 |
| 暗色模式 | 全 UI 适配 `data-theme="dark"` |

## 技术栈

| 技术 | 说明 |
|------|------|
| **纯 HTML/CSS/JS** | 零框架、零构建工具、零 npm 依赖 |
| **Canvas** | 所有图表（曲线图、饼图）原生绘制，不依赖 Chart.js 等库 |
| **IndexedDB** | 浏览器本地数据库，通过 `shared/db-core.js` 统一封装（Promise 风格，自动升级 schema，内置导出导入） |
| **CSS 变量** | 统一设计令牌（`shared/base.css`），全局暗色模式一键切换 |
| **暗色模式** | `data-theme` 属性切换，Canvas 图表跟随主题自适应颜色 |
| **标签系统** | 跨模块统一的标签数据结构，支持 JSON 导出导入 |

### 设计系统

`shared/base.css` 提供完整的设计令牌：
- **主色调**：柔和蓝靛（`#4f5de4`）
- **间距体系**：基于 8px 的 `--jy-space-*` 变量
- **排版**：`--jy-font-size-*` 6 级字号 + 等宽字体
- **语义色**：success / danger / warning / info 四种状态色
- **通用组件**：按钮（`jy-btn`）、输入框（`jy-input`）、选择器（`jy-select`）、弹窗（`jy-modal`/`jy-overlay`）、空状态（`jy-empty`）、表单（`jy-form-group`/`jy-label`）

## 数据存储

- **引擎**：浏览器 IndexedDB
- **封装**：`shared/db-core.js`（`JuYiDB` 类）
- **数据库名**：各模块使用独立数据库（如 `JuYiDB`、`JuYiFitness` 等），互不干扰
- **容量**：通常 > 100MB，足够存储上千条带图记录
- **迁移**：各模块内置 JSON 导出/导入功能（图片以 base64 内嵌）

## 开发约定

- **零依赖**：不引入任何第三方库或框架
- **模块独立**：每个模块有独立的 HTML/CSS/JS，可单独运行
- **共享层**：通用样式和数据库封装放在 `shared/`，模块通过相对路径引用
- **暗色模式**：所有模块必须支持 `data-theme="dark"` 切换
- **中文优先**：UI 文案使用中文
