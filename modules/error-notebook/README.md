# 错题本 (Error Notebook)

JuYi 项目的错题管理模块。

## 功能

- **图文混排**：题目和解析都支持文字+图片，Ctrl+V 即可粘贴截图
- **普通/难题分类**：二分类标记，支持单独筛选
- **科目分类**：预设政治/英语/数学/数据结构/计组/操作系统/计网，支持自定义
- **标签系统**：自由打标签（真题、易错、公式等）
- **复习模式**：单题卡片，按添加时间顺序，断点续复习
- **搜索 & 筛选**：科目、标签筛选 + 文本搜索
- **导出导入**：JSON 格式备份（含图片），跨设备恢复
- **暗色模式**：夜间刷题护眼
- **零依赖**：纯 HTML/CSS/JS，双击即可运行

## 快速开始

### 方式一：从 JuYi 首页进入
在 `JuYi/` 根目录下双击 `index.html`，点击「错题本」。

### 方式二：独立运行
直接双击本目录下的 `index.html`。

### 方式三：迁移到其他项目
复制以下文件/目录：
```
error-notebook/      （本目录）
shared/              （共享层，放在同级）
```

## 复习模式说明

1. 侧边栏选择一个科目
2. 点「开始复习」
3. 按题目添加时间升序，单张卡片逐个展示
4. 操作按钮：
   - **会**：移出难题库 → 推进进度 → 下一题
   - **不会**：移入难题库 → 推进进度 → 下一题
   - **跳过**：不变 → 不推进进度 → 下一题（下次从这题开始）
   - **查看解析**：弹窗显示解析
5. 复习完所有题 → 提示完成 → 可重新开始
6. 「重置进度」可随时从头复习

## 数据存储

- **位置**：浏览器 IndexedDB（完全本地，不上传服务器）
- **数据库名**：`JuYiDB`
- **容量**：通常 > 100MB，够存上千道带图错题
- **备份**：定期使用「导出备份」保存 JSON 文件
