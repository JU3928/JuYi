# 📒 错题本

> JuYi 核心模块——富文本错题管理、按科目分轮复习、进度追踪。

## 功能概览

| 功能 | 说明 |
|------|------|
| **富文本编辑** | 题目 + 解析双栏编辑器，支持加粗/斜体/下划线/列表/图片粘贴 |
| **图片粘贴** | Ctrl+V 粘贴剪贴板截图，自动转 base64 嵌入内容 |
| **科目管理** | 7 个预设科目（政治/英语/数学/408 等），支持自定义添加/删除/改色 |
| **标签系统** | 每道题可打多个标签（如"真题""公式""易错"），侧边栏标签筛选 |
| **难题标记** | 勾选"标记为难题"后卡片显示红色徽章，复习时可切换标记 |
| **分轮复习** | 按科目选择，从上次中断处继续，支持 会/不会/跳过/查看解析/上一题 |
| **复习进度** | 每个科目独立追踪 `lastReviewedIndex`，支持重置进度 |
| **全文搜索** | 搜索标题+题目+答案文本内容 |
| **排序** | 最新添加 / 最早添加 |
| **导出/导入** | JSON 备份，含全部题目 + 复习进度 |
| **系统备份** | 通过首页「一键导出全部」纳入全库备份 |
| **数据迁移** | 自动补充旧记录的 `isHard` / `createdAt` 字段 |
| **暗色模式** | `data-theme="dark"` 完整支持 |

## 数据模型

### IndexedDB

数据库 `JuYiDB`（版本 2），两个 Object Store：

#### `errorNotebook`（主表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | auto | 主键 |
| `subject` | string | 科目（如"数学""数据结构"） |
| `question` | string(HTML) | 题目富文本 |
| `answer` | string(HTML) | 解析富文本 |
| `tags` | string[] | 标签数组 |
| `source` | string? | 来源（如"2024真题卷"） |
| `isHard` | boolean | 是否难题 |
| `createdAt` | number | 创建时间戳(ms) |
| `lastReviewedAt` | number? | 最近复习时间戳 |

索引：`subject`、`createdAt`、`isHard`

#### `reviewProgress`（复习进度）

| 字段 | 类型 | 说明 |
|------|------|------|
| `subject` | string | 科目（主键，非自增） |
| `lastReviewedIndex` | number | 上次复习到的题目索引 |
| `lastReviewDate` | string | 上次复习日期（YYYY-MM-DD） |

### localStorage

| Key | 内容 |
|-----|------|
| `jy_error_notebook_subjects` | JSON: `[{name, color}, ...]` |
| `jy_theme` | `'dark'` \| `'light'` |

## 复习机制

### 流程

1. 侧边栏选择一个科目（只能单选复习）
2. 点击「▶ 开始复习」
3. 系统从 `lastReviewedIndex + 1` 位置开始展示题目
4. 每道题选择：
   - **✅ 会** —— 自动取消难题标记，保存进度，下一题
   - **❌ 不会** —— 自动标记难题，保存进度，下一题
   - **💡 查看解析** —— 弹窗显示解析内容
   - **⏭ 跳过** —— 不保存进度，不修改标记，下一题
   - **◀ 上一题** —— 回退到前一道
5. 复习完所有题目后显示"🎉 恭喜！本周复习完成"
6. 点击「🔄 重新开始」可重置本科目全部进度

### 进度存储

`reviewProgress` 表以科目为主键，每个科目独立追踪。侧边栏统计面板显示每个科目的复习进度（如"复习 5 / 12 题"）。

## 富文本编辑器

### 工具栏

两个编辑器各有一行工具栏：

| 按钮 | 功能 | 实现 |
|------|------|------|
| **B** | 加粗 | `execCommand('bold')` |
| *I* | 斜体 | `execCommand('italic')` |
| U | 下划线 | `execCommand('underline')` |
| • | 无序列表 | `execCommand('insertUnorderedList')` |
| 1. | 有序列表 | `execCommand('insertOrderedList')` |
| 🖼️ | 插入本地图片 | FileReader → base64 → `execCommand('insertImage')` |
| ✧ | 清除格式 | `execCommand('removeFormat')` |

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+V` | 粘贴（自动拦截图片 → base64 嵌入，其他 HTML 可粘贴但保存时经 `sanitizeHtml` 净化） |
| `Enter` | 在编辑器外区域提交保存（编辑弹窗内） |
| `Escape` | 关闭弹窗 |

### 安全策略

所有通过 `innerHTML` 渲染的用户内容均经 `shared/utils.js` 的 `sanitizeHtml()` 净化——基于 DOMParser 白名单机制，移除 `<script>`、`on*` 事件处理器、`javascript:` 伪协议等危险内容。

## 导出/导入

### 模块内导出

点击侧边栏「💾 导出备份」生成 JSON 文件：

```json
{
  "_format": "JuYiDB/1",
  "exportedAt": "2026-07-29T...",
  "stores": {
    "errorNotebook": [{...}, ...],
    "reviewProgress": [{...}, ...]
  },
  "_subjects": [{...}, ...]
}
```

导入时覆盖清空当前全部数据，从备份文件恢复。

### 系统备份

通过首页「📦 一键导出全部」将该模块纳入全量备份（`JuYiSysBackup/1` 格式），与其他模块一道恢复。

## 数据兼容

### 旧版迁移

`_migrateData()` 在每次初始化时自动检查并修复：
- 补充缺失的 `isHard` 字段（默认 `false`）
- 补充缺失的 `createdAt` 字段（尝试从旧字段 `created_at` 转换，否则用当前时间）

### 格式兼容

`shared/db-core.js` 的 `importAll` 同时接受 `JuYiDB/1` 和 `JuYiDB/2` 两种历史格式。
