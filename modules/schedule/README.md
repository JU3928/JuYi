# 📅 计划表

> 考研复习日程管理工具——双场景、时间线可视化、打卡统计、日历回顾。

## 功能

| 功能 | 说明 |
|------|------|
| **双场景切换** | 常规日 / 牛客周赛日，一键切换，固定任务时段不变 |
| **时间线可视化** | 07:00-23:00 纵向时间轴，按任务类型着色 |
| **表格勾选** | 精确到时段粒度的复选框打卡 |
| **加权完成率** | 固定任务 70% + 弹性任务 30% = 综合完成率 |
| **一键勾选** | 批量勾选今日所有固定任务 |
| **日历视图** | 月度日历，单元格颜色深浅对应完成率，点击可回顾任意历史日期 |
| **连续打卡** | 从今天往前数，统计连续有打卡记录的天数（4 级徽章：📌 / 🔥 / ⭐ / 👑） |
| **勤奋指数** | 本月完成率 ≥80% 的天数占比 |
| **每日鸡汤** | 根据当前时间和完成率动态生成鼓励语 |
| **只读回顾** | 点击日历中的历史日期以只读模式查看，不可修改 |
| **暗色模式** | 支持 `data-theme="dark"` |

## 数据存储

纯 `localStorage`，无 IndexedDB。

- **Key 格式**：`jy_sched_YYYY-MM-DD`（如 `jy_sched_2026-07-20`）
- **Value**：JSON `{ date: "2026-07-20", checks: { "07:00-07:30": true, ... } }`

每条记录的 `checks` 以时段字符串（如 `"08:00-09:30"`）为键，布尔值为值。

### 牛客周赛日（niuke）

19:00-21:00 替换为「牛客周赛」（类型为 `competition`，不算入完成率），午间弹性时段标注「建议今日暂停」。

### 跨场景勾选共享

同名时段（如 08:00-09:30 英语早）在常规日和牛客日之间**共享勾选状态**——切换到另一场景时，相同 slot 的勾选自动继承。

## 核心原则

1. 🛡️ **固定任务**（英语早 / 数学 / 408 / 英语阅读 / 运动）不缩短、不移动、不取消
2. 🏃 **16:00-17:00 运动**永远锁定
3. 📖 **15:30-16:00 英语阅读**为固定任务，绝不可压缩
4. 🔢 建议每月牛客比赛 2-3 次

## 完成率计算

```
综合完成率 = 固定完成率 × 0.7 + 弹性完成率 × 0.3
```

- 比赛类型（`competition`）不参与完成率计算
- 牛客日中标注「建议今日暂停」的弹性任务不参与计算（`isNiukeElastic`）

## 使用方式

双击 `index.html` 打开，或通过 GitHub Pages 访问：

```
https://ju3928.github.io/JuYi/modules/schedule/index.html
```

- 顶部切换场景（常规日 / 牛客周赛日）
- 表格中勾选完成的任务
- 右侧日历点击任意日期回顾历史
- 点击「🔙 返回今日」回到当天
